# Проверки набора ClaudeKit

Общие для всех проектов, параметры — `.claude/kit.json` (раздел `checks`). Только Python 3.8+; на Windows — `python` или `py`, на Linux — `python3`.

| Скрипт | Что проверяет | Параметры | Время |
|---|---|---|---|
| `check_links.py` | относительные ссылки в `.md` ведут на файл и заголовок | `links_ignore` | доли секунды |
| `check_ids.py` | идентификаторы требований: один раз определены, ссылки на существующие; `--unused` — на какие никто не ссылается | `ids` | доли секунды |
| `check_page.py` | прототип открывается без ошибок JS и потерянных файлов, обе темы, 1440 и 360 px; `--shots <папка>` — снимки | `pages` | секунды; нужен playwright |

Итог в последней строке, `FAIL` — находка, `ЗАМЕЧАНИЕ` — посмотреть глазами. Код выхода 1 — есть `FAIL`.

Своя проверка проекта — в `tools/` рядом, не в `tools/kit/`: эта папка перезаписывается при обновлении набора.
