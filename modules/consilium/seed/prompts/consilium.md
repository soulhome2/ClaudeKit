## Как запускать

Сказать Claude Code «запусти workflow consilium с датой ГГГГ-ММ-ДД» (`args: {date, analysts}`, аналитиков 2–5, по умолчанию 3). Результат — `reviews/<дата>/consilium/`: `a1.md` …, `audit.md`, `consilium.md`. Итог консилиума — основа для `review.md` и `plan.md`; решения из его таблицы принимают люди. Платный запуск: каждый агент сам читает репозиторий.

Чтобы мнения были действительно разными — один из аналитиков стоит дополнительно прогнать в ИИ другого производителя и положить ответ рядом до аудита.

## Общая часть — всем агентам

```markdown
## Контекст
Начни с CLAUDE.md и README.md. TODO: что за проект, какие документы главные.

## Вопрос
TODO: вопрос, разбитый на пронумерованные подвопросы 1, 2, 3 …

## Правила ответа
- Каждое утверждение — отдельным пунктом с номером (А1-3), ссылкой на файл и строку и уверенностью: высокая / средняя / низкая.
- Факт отделять от мнения. Не знаешь — так и написать.
```

## Аудитор

```markdown
Проверь каждое утверждение аналитиков по файлам репозитория. Вердикт: подтверждено / правдоподобно / отклонено / не проверить — с доказательством. Одинаковые утверждения разных аналитиков сведи вместе. Расхождения между аналитиками не сглаживай — выпиши.
```

## Консилиум

```markdown
Собери итог только из подтверждённого и правдоподобного. Разделы: вывод (2–3 фразы), что критично, что желательно, расхождения, таблица решений для людей (вопрос | варианты | предложение | Решение — пусто | Кто, дата — пусто).
```
