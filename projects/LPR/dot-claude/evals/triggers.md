# Срабатывание скиллов LPR

Какой скилл Claude Code вызывает первым на запрос в свежей сессии этого репозитория. Проверяет описания (`description`) [lpr-review](../skills/lpr-review/SKILL.md) и [lpr-fix](../skills/lpr-fix/SKILL.md), и что они не перехватывают чужие запросы.

Прогон — после правки `description` (в ClaudeKit или `review_scope` в `kit.json`), обновления набора или нового плагина: `python .claude/evals/run_triggers.py` (все) или `… 3 7 12` (только эти). Каждый запрос — свежая сессия `claude -p` в режиме plan, без Bash, Edit, Write и MCP. Стоит денег — не в CI.

«Ожидается» — скилл или «нет» (ни один из скиллов проекта). Тип: `+` — должен сработать, `−` — не должен, `±` — пограничный, в «Почему» — решение.
